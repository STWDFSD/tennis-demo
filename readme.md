# Tennis Tournament Demo

## Overview
This project is a static demo of a tennis tournament website using Sitemesh and Velocity for layout and templating.

## Project Structure
- Home Page: Displays a list of tennis tournaments with placeholders for name, location, dates, and prize pool.
- Details Page: Provides a static layout with placeholders for a tournament's schedule, players, and venue details.

## Running the Project Locally

1. Clone the repository:
    ```bash
    git clone [<repository-url>](https://github.com/STWDFSD/tennis-demo.git)
    cd tennis-demo
    ```

2. Build the project using Maven:
    ```bash
    mvn clean package
    ```

3. Deploy the project in a servlet container like Apache Tomcat.

4. Access the application:
    - Home Page: http://localhost:8080/tennis-tournament-demo/
    - Details Page: http://localhost:8080/tennis-tournament-demo/details
